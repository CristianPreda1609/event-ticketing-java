# Event Ticketing (Java)

Project for the Advanced Object-Oriented Programming (PAO) course at FMI, University of Bucharest.

A ticketing system for events (concerts, festivals, clubs) with users and roles, locations and tickets. It has a DAO layer over a relational database and an audit service that logs actions.

## Structure

- `Etapa1/`: stage 1, the domain model and services
- `Etapa 2/`: stage 2, database persistence (DAO, `DbConnection`, `DatabaseInitializer`) and audit
- `Etapa2_Modificat/`: revised stage 2

Database credentials in the code are local development defaults.
